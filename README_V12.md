# Sequence-CloV v12 — Frozen-Partition Research Experiments

This is an **offline research demonstrator**. It does NOT execute, unpack, sandbox, or download APK files. It does not verify whether the exported trace actually came from the alleged APK or whether labels are correct.

## Run (Windows PowerShell)

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Open **Reproducible experiments (v12)**, upload a dataset-release ZIP exported from the **Real-trace release builder (v8)**, choose models and a seed, then run. Save the results ZIP with metrics, predictions, source hashes, settings and audit metadata.

Try with `example_v12_release_SYNTHETIC.zip`. Its event sequences, class labels and SHA-256 values are **synthetic examples**. They are not observed Android malware behaviour and must not be described as authentic results.

## Prerequisites for valid research claims

- Obtain original exported behavioural reports through an institution-approved **isolated** Android analysis environment.
- Record APK SHA-256 values independently of the report, run environment, operating system, execution conditions, collection timestamps, and source/licensing details.
- Include a legitimate benign application cohort. Folder names alone are not independent label verification.
- Avoid splitting the same APK, repackaged near-duplicates, or related test collections between training and testing; exact-hash and exact-sequence checks are necessary but insufficient.
- Reserve the held-out test partition for a single final analysis; tune parameters on a separate validation partition and report uncertainty across multiple seeds or folds.
- Maintain separate data provenance and ethics/safety approvals. The Streamlit app never executes malicious packages.
